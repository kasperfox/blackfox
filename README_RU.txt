BlackFox Launcher v2.0.0 (Windows 10 / 11) — Minecraft 1.21.1 NeoForge 21.1.266

1. Как получить чистый один файл .exe БЕСПЛАТНО (рекомендуемый способ — через GitHub Actions):
   - Создайте новый репозиторий на https://github.com
   - Загрузите содержимое этой папки в репозиторий (включая скрытую папку .github/workflows/build-launcher.yml)
   - Перейдите на вкладку Actions -> "Build BlackFox Launcher (.exe)" -> Run workflow
   - Через 2-3 минуты в разделе Releases появятся готовые файлы:
     * BlackFox-Launcher-Portable.exe (один чистый .exe файл для игроков — Node.js НЕ нужен!)
     * BlackFox-Launcher-Setup.exe (установщик Windows)

2. Локальная сборка или запуск на своём ПК (нужен Node.js 22 LTS):
   - Запустите build-exe.bat — готовые .exe появятся в папке dist\
   - Либо запустите start-launcher.bat для мгновенного запуска без компиляции .exe

3. Автоматические обновления для игроков:
   - Быстрые патчи кода/интерфейса лаунчера приходят сами без перекачивания .exe
   - Если выпустите новый .exe в GitHub Releases и укажете репозиторий в панели сервера, старый .exe сам обновится на новый

4. Защита от вылетов (Crashpad) и зеркала:
   - При первом сбое видеодрайвера лаунчер сам переключается в безопасный режим графики
   - Встроены резервные зеркала Mojang / NeoForge (BMCLAPI + прокси вашего сервера)
